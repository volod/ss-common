# Task Records

Copy the [template](template.md) at task start to `NNNN-<group>-<task-id>.md` using the
[naming rules](../../guide/planning-workflow.md#record-file-naming), then add a row here. Records
keep the full task and its evidence after it leaves the [plan](../plan.md). Tasks finished while
ss-common was staged keep their records in the staging repository.
